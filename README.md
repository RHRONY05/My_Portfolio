> **Production Web & AI Portfolio** for **Muhammad Rony (RH.RONY)** — Software Developer & CSE Undergrad at Chittagong University of Engineering and Technology (CUET).  
> 🌐 **Live Site**: [rhrony05.me](https://rhrony05.me)

---

## ⚡ Key Highlights

* **Urban Graffiti Hero**: Full-screen street graffiti mural with responsive framing and an interactive 2D canvas runner game (*Street Curb Runner*).
* **3D Comic Book Dossier**: Interactive hardcover volume with procedural paper ridges, dynamic lighting, and realistic 3D page-flip kinematics powered by Three.js.
* **3D Mahoraga Load Balancer**: Eight-spoked adaptation halo orchestrating modern AI engineering tools with procedural Web Audio ratchet effects.
* **Interactive Project Deck**: 3D carousel shelf featuring 8 production case studies with interactive browser mockup viewports.
* **Dynamic Design System**: 4 live themes (*Monolithic Onyx, Celadon Forest, Midnight Amethyst, Prussian Blue*) and 4 live typography presets.
* **Core Web Vitals Standard**: **99 Desktop / 86+ Mobile** Lighthouse scores via viewport-gated render-prop 3D mounting (`LazyViewportMount.tsx`).

## 🛠️ Tech Stack

* **Framework**: Next.js 16 (App Router, Turbopack)
* **Runtime & UI**: React 19, TypeScript
* **Styling**: Tailwind CSS v4 (CSS-first config)
* **3D Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
* **Motion & Physics**: Framer Motion
* **Image Optimization**: Sharp

## 🚀 Getting Started

### Prerequisites
* Node.js 18+ (Node 20+ recommended)
* npm, pnpm, or bun

### Local Development
```bash
# Clone the repository
git clone https://github.com/RHRONY05/My_Portfolio.git

# Install dependencies
npm install

# Start development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

### Production Build
```bash
# Typecheck
npx tsc --noEmit

# Static export compilation
npm run build

# Preview production build locally
npm run start
```
